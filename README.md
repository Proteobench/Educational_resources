# Educational resources

This repository is a compact collection of training materials for the ProteoBench/Post-processing workflows, with a focus on notebook-based tutorials that are easy to run and explore.

## Tutorial notebooks

These notebooks are the main entry points for learning and hands-on use:

- [tutorial_jupyter_notebooks/local_usage_walkthrough.ipynb](tutorial_jupyter_notebooks/local_usage_walkthrough.ipynb)
  A walkthrough for running the workflow locally, preparing inputs, and following the analysis step by step.

- [tutorial_jupyter_notebooks/example_visualisations.ipynb](tutorial_jupyter_notebooks/example_visualisations.ipynb)
  A set of example visualisations to help interpret output tables and plots for common use cases.

## Supporting reference material

The remaining folders are supplementary and intended as background or reference material rather than the main learning path:

- [data](data) — example input files and small datasets used in teaching and testing.
- [posthoc_analyses](posthoc_analyses) — additional post-hoc analyses and more detailed reference work for deeper investigation.

For most users, start with the tutorial notebooks above. The supporting folders are useful for context, reproducibility, and extended examples.
